## 中文

`0.1.4` 补全 Grok 与 Codex 的剩余额度展示，拆分 Codex 的 5 小时和每周窗口，并让侧栏图标随当前 Provider 切换。

### 额度展示

- Grok 显示剩余额度百分比、当前周期和重置时间；优先使用 Grok 插件返回的剩余百分比，必要时由已用百分比换算。
- Codex 将已有 RPC 的已用百分比换算成剩余百分比，分别完整显示 5 小时与每周窗口及各自重置时间。
- 额度窗口改为独立、可换行的侧栏文本，不再因单行省略而隐藏后半段数据。

### Provider 图标

- 选择 Grok 时显示 Grok 图标。
- 选择 Codex 时显示 ChatGPT/OpenAI 图标。
- 选择 DeepSeek 或无法识别的自定义 Provider 时显示 DeepSeek 图标。
- 图标内联于客户端产物、继承当前主题颜色，不会增加网络请求或运行时依赖。

### 兼容性与安全边界

- Grok/Codex 仍是可选插件；缺失或 RPC 不兼容时仅降级为“额度来源不可用”。
- 本插件不改变 Grok/Codex 的登录、模型、设置或 RPC 行为，只保留侧栏显示所需的剩余百分比和重置窗口。
- DeepSeek 余额、未知 Provider 回退和官方充值入口保持不变。

### 验证限制

- 自动化验证覆盖额度字段投影、Grok/Codex 分窗口渲染、Provider 图标映射、长文本换行、Provider 切换和包内容。
- 未执行真实 Grok/Codex 账户额度读取或真实 Harness GUI 验收；未执行真实 DeepSeek 余额查询或付款。

安装：

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.4
dsh web
```

<summary>English release notes</summary>

`0.1.4` adds complete remaining-quota presentation for Grok and Codex, separates the Codex five-hour and weekly windows, and switches the sidebar icon with the current Provider.

### Quota presentation

- Grok shows the remaining percentage, current period, and reset time. It prefers the remaining percentage returned by the Grok plugin and derives it from the used percentage only when needed.
- Codex converts the used percentages from its existing RPC into remaining percentages and shows the five-hour and weekly windows with their respective reset times.
- Quota windows now render as separate wrapping sidebar lines instead of losing trailing data to single-line ellipsis.

### Provider icons

- Grok selections use the Grok icon.
- Codex selections use the ChatGPT/OpenAI icon.
- DeepSeek and unknown custom Provider fallbacks use the DeepSeek icon.
- Icons are embedded in the client artifact, inherit the current theme color, and add no network request or runtime dependency.

### Compatibility and security boundaries

- Grok and Codex remain optional. Missing or incompatible RPCs degrade only to “quota source unavailable.”
- This plugin does not change Grok/Codex authentication, models, settings, or RPC behavior. It retains only the remaining percentages and reset windows required for display.
- DeepSeek balance, unknown-Provider fallback, and the official top-up entry remain unchanged.

### Verification limits

- Automated checks cover quota projection, separate Grok/Codex window rendering, Provider icon mapping, long-text wrapping, Provider switches, and package contents.
- No live Grok/Codex quota read or live Harness GUI acceptance was performed. No real DeepSeek balance query or payment was performed.

Install:

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.4
dsh web
```

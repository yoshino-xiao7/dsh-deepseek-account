## 中文

`0.1.5` 优化 Codex 额度可读性，在每轮对话结束后主动刷新当前 Provider，并让 DeepSeek 账户设置项使用对应的鲸鱼图标。

### 主要变化

- Codex 的 5 小时和每周额度改为两个紧凑信息块：窗口与剩余百分比位于主行，重置时间位于次级行。
- 当前会话从运行变为空闲时，主动刷新一次当前 Provider；初始空闲、重复空闲通知和会话切换不会误触发，也不使用轮询。
- 将“DeepSeek 账户”设置导航的通用齿轮替换为 DeepSeek 鲸鱼图标；重复渲染不会重复插入，插件卸载时恢复 Harness 原图标。

### 兼容性与安全边界

- 图标适配只匹配本插件拥有的中英文设置 label，不修改其他设置项。
- 本版本不接入 DeepSeek 网页登录、用量分析或插件内充值，也不读取网页 Cookie、账户密码或支付数据。
- Grok/Codex 仍是可选数据源，其登录、模型、设置与 RPC 行为不变。

### 验证限制

- 自动化测试覆盖配额分层渲染、Provider 图标、设置导航图标的挂载/去重/恢复，以及单次对话完成刷新。
- 未执行真实 Grok/Codex 账户读取、真实 DeepSeek 余额请求、网页登录或付款；真实 Harness GUI 视觉验收仍需安装后确认。

安装：

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.5
dsh web
```

<summary>English release notes</summary>

`0.1.5` improves Codex quota readability, refreshes the current Provider after each completed conversation turn, and gives the DeepSeek account settings entry its matching whale icon.

### Changes

- Codex five-hour and weekly quotas render as compact blocks, with the window and remaining percentage on the primary row and reset time on a secondary row.
- A current-session running-to-idle edge refreshes the selected Provider once. Initial idle state, duplicate idle notifications, and session switches do not trigger false refreshes; no polling is used.
- The generic settings gear beside “DeepSeek account” is replaced with the DeepSeek whale icon. Re-renders do not duplicate it, and plugin cleanup restores the Harness icon.

### Compatibility and security boundaries

- The icon adapter matches only this plugin's Chinese and English settings labels and does not modify other entries.
- This release does not add DeepSeek web login, usage analytics, or in-plugin payment, and it does not read web cookies, passwords, or payment data.
- Grok and Codex remain optional data sources; their authentication, models, settings, and RPC behavior are unchanged.

### Verification limits

- Automated tests cover quota hierarchy, Provider icons, settings-icon mount/deduplication/restoration, and one refresh per completed conversation turn.
- No live Grok/Codex quota read, DeepSeek balance request, web login, or payment was performed. Live Harness GUI visual acceptance remains pending installation.

Install:

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.5
dsh web
```

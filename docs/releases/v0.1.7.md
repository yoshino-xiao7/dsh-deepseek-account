## 中文

`0.1.7` 修复本插件与官方 Cordis Plugin 等全宽侧栏 footer 入口同时启用时，账户入口被挤出侧栏的问题。

### 主要变化

- 当同一 sidebar footer 存在多个全宽入口时，将这些入口纵向排列，避免横向溢出。
- 展开侧栏的账户卡片与收起侧栏的图标入口均使用同一兼容布局。
- 兼容层只作用于本插件账户入口的实际父容器，不依赖官方插件的私有类名。

### 兼容性与安全边界

- 不修改官方 Cordis Plugin、其他插件或 DeepSeek 桌面端代码。
- 不改变 DeepSeek、Grok 或 Codex 的账户读取、认证、模型、设置及 RPC 行为。
- 不新增网页登录、用量分析或插件内充值能力。

### 验证限制

- 自动化回归测试覆盖官方全宽 footer 入口共存时的纵向布局，并禁止依赖官方私有类名。
- 已通过模块测试、构建和 npm 打包预检；真实 Harness GUI 视觉验收仍需安装并重启后，在 Cordis Plugin 启用状态下确认。

安装：

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.7
dsh web
```

<summary>English release notes</summary>

`0.1.7` fixes the account entry being pushed outside the sidebar when this plugin and full-width official footer entries such as Cordis Plugin are enabled together.

### Changes

- Footer entries are stacked vertically when multiple full-width actions share the same sidebar footer, preventing horizontal overflow.
- The expanded account card and collapsed icon rail use the same compatibility layout.
- The compatibility layer targets the account entry's actual parent container and does not depend on private classes from official plugins.

### Compatibility and security boundaries

- This release does not modify Cordis Plugin, other plugins, or DeepSeek desktop application code.
- DeepSeek, Grok, and Codex account reads, authentication, models, settings, and RPC behavior are unchanged.
- No web login, usage analytics, or in-plugin payment capability is added.

### Verification limits

- Automated regression tests cover vertical layout alongside an official full-width footer action and prohibit dependencies on official private class names.
- Module tests, build, and npm pack preflight passed. Live Harness GUI visual acceptance remains pending installation, restart, and confirmation with Cordis Plugin enabled.

Install:

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.7
```

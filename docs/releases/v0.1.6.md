## 中文

`0.1.6` 修正 DeepSeek 账户设置项同时显示齿轮和鲸鱼的问题，并进一步精简侧栏账户信息的视觉层级。

### 主要变化

- DeepSeek 鲸鱼图标现在会原位替换 Harness 通用齿轮，而不是追加在齿轮旁边。
- 即使 Harness 样式覆盖 HTML `hidden`，或在同一个设置按钮内重新渲染齿轮 SVG，插件也会保持只显示一个鲸鱼图标。
- 侧栏不再重复显示“Codex 额度”“Grok 额度”或“账户余额”等 Provider 标题，由对应图标承担视觉识别。
- 移除展开侧栏卡片及 Codex 5 小时/每周额度行的装饰性底色；Grok 和 DeepSeek 信息同样直接融入侧栏背景。
- 可访问名称仍保留 Provider 和完整账户信息；插件卸载时会恢复 Harness 原图标及其原始样式。

### 兼容性与安全边界

- 图标适配只匹配本插件拥有的中英文“DeepSeek 账户”设置项，不修改其他导航项或桌面端代码。
- 本版本不接入 DeepSeek 网页登录、用量分析或插件内充值，也不读取网页 Cookie、账户密码或支付数据。
- Grok/Codex 仍是可选数据源，其认证、模型、设置和 RPC 行为不变。

### 验证限制

- 自动化测试覆盖高优先级隐藏原齿轮、Harness 原位重绘、鲸鱼去重、卸载恢复、图标-only 标题以及无底色账户详情。
- 已通过模块测试、构建和 npm 打包预检；真实 Harness GUI 视觉验收仍需安装并重启后确认。

安装：

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.6
dsh web
```

<summary>English release notes</summary>

`0.1.6` fixes the settings row showing both the generic gear and the DeepSeek whale, and further simplifies the sidebar account presentation.

### Changes

- The DeepSeek whale now replaces the Harness gear in place instead of being appended beside it.
- The plugin keeps exactly one whale visible even when Harness CSS overrides HTML `hidden` or the shell re-renders its gear SVG inside the same settings button.
- The sidebar no longer repeats Provider headings such as “Codex quota”, “Grok quota”, or “Account balance”; the corresponding icon provides visual identity.
- Decorative backgrounds are removed from expanded sidebar cards and Codex five-hour/weekly rows. Grok and DeepSeek details also sit directly on the sidebar background.
- Accessible names still retain the Provider and complete account details. Plugin cleanup restores the Harness icon and its original styles.

### Compatibility and security boundaries

- The icon adapter matches only this plugin's Chinese and English “DeepSeek account” settings entry. It does not modify other navigation entries or desktop application code.
- This release does not add DeepSeek web login, usage analytics, or in-plugin payment, and it does not read web cookies, passwords, or payment data.
- Grok and Codex remain optional data sources; their authentication, models, settings, and RPC behavior are unchanged.

### Verification limits

- Automated tests cover high-priority gear hiding, in-place Harness re-renders, whale deduplication, cleanup restoration, icon-only headings, and background-free account details.
- Module tests, build, and npm pack preflight passed. Live Harness GUI visual acceptance remains pending installation and restart.

Install:

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.6
dsh web
```

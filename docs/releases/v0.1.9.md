## 中文

`0.1.9` 修复升级 DSH 后 DeepSeek 账户页显示“暂时无法读取余额”、侧栏余额为空的问题。

### 修复

- 余额 HTTP RPC 同时等待 `connection` 和 `webServer`，并由 Connection 管理注册效果的生命周期，避免启动期间遗漏路由。
- HTTP 服务重启时重新注册余额路由；插件卸载时清理路由。
- peer dependency 声明新增 Harness `0.1.5-rc.2` 和 Cordis `4.0.2`，保留此前声明的版本。

### 验证与范围

- 12 项测试与构建通过；新增回归使用真实 Cordis/Connection 模块，覆盖 HTTP 服务晚启动、重启及插件卸载。
- 独立安装的 Harness `0.1.5-rc.2` Host fixture 通过；CI 增加相同检查。
- 本机 DeepSeek YukiRyou / DSH `0.1.5-rc.2` 已验证真实账户余额读取：侧栏和设置页均恢复，刷新可用。
- 本次未重新完成旧版 Harness 的完整验收，也未验证其他账户插件或付款流程。

安装：

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.9
```

安装后重启使用该 profile 的 DSH。

<summary>English release notes</summary>

`0.1.9` fixes unavailable DeepSeek balances after a DSH upgrade, affecting both the account settings page and sidebar.

### Fix

- Wait for both `connection` and `webServer` before registering the balance HTTP RPC, leaving registration effects owned by Connection's lifecycle.
- Restore the route after an HTTP server restart and remove it when the plugin unloads.
- Add Harness `0.1.5-rc.2` and Cordis `4.0.2` to the declared peer versions while retaining the existing versions.

### Verification and scope

- All 12 tests and the build passed. The new regression uses real Cordis/Connection modules to cover delayed HTTP server startup, server restart, and plugin unload.
- An independently installed Harness `0.1.5-rc.2` Host fixture passed; CI now runs the same check.
- Live balance reads and refresh were verified in the installed DeepSeek YukiRyou application running DSH `0.1.5-rc.2`, in both the sidebar and settings page.
- Full acceptance on older Harness versions, other account plugins, and payment flows was not repeated in this release.

Install:

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.9
```

Restart the DSH instance using this profile after installation.

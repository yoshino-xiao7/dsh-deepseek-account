## 中文

`0.1.8` 修复 `0.1.7` 未实际生效的 Cordis Plugin 侧栏兼容规则，使官方 Cordis 入口与账户入口真正纵向排列。

### 根因与修复

- Harness renderer 为 `sidebar.footer.action` list slot 创建了带内联 `display: contents` 的 anchor。
- `0.1.7` 只在该 anchor 上设置 `flex-direction: column`；因为 `display: contents` 不生成布局盒，所以规则虽然命中，Cordis 与账户入口仍会横向互相挤压。
- 本版本只匹配直接包含本插件 card/rail 的 `data-slot="sidebar.footer.action"` anchor，用 `display:flex!important` 覆盖其内联值，再建立全宽纵向布局。
- 不依赖 Cordis 或 sidebar 的构建期私有类名，也不覆盖官方入口自身的宽度、定位或弹层样式。

### 验证

- 回归测试实际执行插件样式安装并检查最终注入 CSS，不再只匹配源码字符串。
- 已在正式安装的 DeepSeek YukiRyou 中，以 Cordis Plugin 运行状态分别验收展开和收起侧栏：Cordis 与 Grok 账户入口均完整位于侧栏内并纵向排列。
- 11/11 模块测试、构建和 npm 打包预检通过。

### 边界

- 只修改当前插件，不修改 DeepSeek YukiRyou 桌面端、官方 Cordis Plugin 或其他插件。
- DeepSeek、Grok 与 Codex 的账户读取、认证、模型、设置和 RPC 行为不变。

安装：

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.8
dsh web
```

<summary>English release notes</summary>

`0.1.8` fixes the ineffective Cordis Plugin sidebar compatibility rule from `0.1.7`, so the official Cordis entry and the account entry are actually stacked vertically.

### Root cause and fix

- The Harness renderer creates a `sidebar.footer.action` list-slot anchor with inline `display: contents`.
- `0.1.7` only set `flex-direction: column` on that anchor. Since `display: contents` creates no layout box, the rule matched but Cordis and account entries still competed in the outer horizontal flex row.
- This release matches only the `data-slot="sidebar.footer.action"` anchor that directly contains this plugin's card or rail, overrides the inline value with `display:flex!important`, and then establishes a full-width vertical layout.
- It does not depend on private build-time classes from Cordis or the sidebar, and it does not override the official entry's width, positioning, or panel styles.

### Verification

- The regression test executes the plugin style installer and checks the final injected CSS instead of matching source-code text only.
- Live acceptance passed in the installed DeepSeek YukiRyou application with Cordis Plugin running, in both expanded and collapsed sidebar modes. The Cordis and Grok account entries remained fully inside the sidebar and stacked vertically.
- All 11 module tests, the build, and npm pack preflight passed.

### Boundaries

- This release changes only the current plugin; it does not modify DeepSeek YukiRyou, the official Cordis Plugin, or other plugins.
- DeepSeek, Grok, and Codex account reads, authentication, models, settings, and RPC behavior are unchanged.

Install:

```sh
dsh plugin --profile web add dsh-deepseek-account@0.1.8
dsh web
```
